# UI-Design-VioLearn-Hangeul

Proyek digital ini dibuat sebagai tempat eksplorasi dan eksperimenku dalam menerapkan framework Design Thinking, mulai dari tahap riset pengguna sampai pembuatan prototype. Status proyek saat ini masih Work In Progress (WIP) alias setengah matang, jadi tampilannya baru selesai di fitur-fitur tertentu aja. Sisanya? Ya nanti dilanjut lagi kalau ada waktu, kuota, dan mood yang mendukung wkwk. Meskipun belum kelar 100%, aku tetap senang bisa menuangkan ide-ide kreatifku ke dalam desain interface di Figma ini.
